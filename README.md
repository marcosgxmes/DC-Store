# 🛒 DC Store

O **DC Store** é um e-commerce desenvolvido para a venda de mangás e histórias em quadrinhos (HQs), com foco em oferecer uma experiência de navegação moderna, intuitiva e responsiva.

O projeto utiliza **React, TypeScript, Tailwind CSS e Firebase**, combinando uma interface dinâmica com recursos de gerenciamento de dados e autenticação de usuários.

### ✨ Funcionalidades

- 🔐 Autenticação de usuários.
- 🛡️ Proteção de rotas para acesso seguro às páginas.
- 📚 Catálogo de mangás e HQs.
- 🗄️ Integração com Firebase para armazenamento e gerenciamento de dados.
- 📱 Interface responsiva e componentes reutilizáveis.

### 🛠️ Tecnologias utilizadas

- **React.js** — construção de interfaces.
- **TypeScript** — tipagem estática e maior confiabilidade do código.
- **Tailwind CSS** — estilização e desenvolvimento de interfaces responsivas.
- **Firebase** — autenticação e gerenciamento de dados.
